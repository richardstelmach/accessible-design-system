### Card

Sources: components/card/card.yaml and card.md, existing Card/Badge/Link and heading/focus contracts, and tokens/components/card.json. The native div ref never becomes a link widget or tab stop. Optional title uses strong body text by default; headingLevel 2–6 and compact H5 appearance are independent. titleHref requires a title; wholeCardClickable requires that linked title and defaults off. Native titleLinkAttributes preserve navigation/router integration without replacing owned content/href/semantics. Optional intrinsic image requires src, explicit alt and positive width/height, supports cover/contain, position and responsive source metadata; one existing Badge may overlay an image. Content and action slots collapse when absent and own their internal typography/paragraph spacing.

The real title link is always the primary destination. After mount, the surface delegates only a completed unmodified primary pointer activation. Native links/controls, labels, editable content, widgets, nested card/opt-out boundaries and exposed shadow paths are excluded without requiring stopPropagation. Selection intersecting the card, selection/drag/movement, scrolling, pointer cancellation, context menu and default-prevented clicks suppress forwarding. Slow deliberate clicks remain valid; there is no duration cutoff. Recursive/programmatic forwarded clicks cannot loop. Native title modifiers/context menus/target/rel/download remain native; background modified/middle/right activation is ignored. Opaque shadow integrations can mark their host data-owla11y-card-ignore. Real touch long-press and broader assistive-technology acceptance remain manual.

Root border/fill/radius and slot spacing reuse existing tokens; only media clips. A named inner container query changes horizontal media to a 12rem column once the root's available inner width reaches canonical 32rem. The assembler resolves that token into a literal size-query condition, rather than attempting var() in a query. Vertical layout is the fallback. Tests check both sides of the threshold (514px versus 513px outer width with the 2px border), full-height horizontal media, reserved 16:9 vertical media, contain treatment and RTL/reflow. No media means the body retains full width. An empty shell is padding plus border (34px at the reference root), not a loading state.

### Breadcrumb

Sources: components/breadcrumb/breadcrumb.yaml and breadcrumb.md, seven existing spacing aliases and the composed link style recipe. The nav ref names a real landmark containing an ordered hierarchy. Unique nonempty keyed ancestors require descriptive text and native hrefs; optional currentPage is plain text with aria-current=page. No ancestors omits the landmark. Omitting currentPage leaves the final ancestor as an ordinary link.

Controlled expanded/onExpandedChange excludes defaultExpanded; uncontrolled preference defaults false. The same anchors remain mounted through presentation changes. A hidden, inert, text-only sample measures the compact path independently of the expanded layout, bounding each individual label to the available inner width. ResizeObserver, font loading, content/prop changes, resizing and focus updates recheck actual fit. The layout offers native horizontal scrolling only when needed, with a Show full path button outside the clipped viewport; expanded wraps complete items. No hidden intermediate ancestors, ellipsis menu, truncation, roving focus or live repetition is added.

The user preference survives resizing and controlled owners may decline requests. When overflow ends, an unfocused toggle disappears; a focused toggle remains until blur. Deliberate collapse resets to logical start while preserving/revealing a focused link. Focus clearance, scroll padding/margins and native scrollIntoView handle the complete indicator without assuming RTL scrollLeft conventions. SSR/no-JavaScript and unavailable measurement retain a wrapping path without a dead toggle. Print wraps the full path and omits the toggle. Browser testing found and corrected the print rule's specificity so screen overflow styling cannot defeat it.

### Pagination

Sources: components/pagination/pagination.yaml and pagination.md, six spacing/current-colour aliases, the filled selected semantic family, shared TextInput/Button/Link and composed link style. Known exact safe-integer totals and a valid currentPage are mandatory; total zero uses currentPage=1 sentinel. Zero/one page renders nothing. The canonical seven-position algorithm uses bounded time/space, retains both endpoints/current and meaningful omissions, and never allocates totalPages entries. Whole values are formatted without abbreviation. formatPageLabel includes the entire visible formatted number. Each numbered list has one current real link; compact summary supplies the one visible current marker instead. Unavailable directions/endpoints are omitted.

presentation=auto compares actual target/translated-label/number widths with the available container; explicit numbered wraps, and compact exposes summary, Previous/Next and First/Last. A focused numbered control defers hiding until focus leaves. A text-only inert measure introduces no duplicate links, tab stops or current semantics. Missing measurement retains the usable numbered baseline. Native directions, numbers and endpoints preserve hrefs and ordinary keyboard/modifier behaviour. Current/default/hover/pressed colour pairs and independent focus use the source aliases.

The optional pageJump requires explicit jumpForm={action,pageName,hiddenFields?}. This refines the draft adapter so native GET fallback does not guess how an arbitrary pageHref function encodes routes/query parameters. Supply existing filter/sort fields explicitly with unique names. Do not nest the generated form. The native required text input uses numeric inputMode and a 20ch content width constrained to its column, not a thousands-option Select or number spinbutton. The Go button is compact, matching Figma. Before enhancement, native required/pattern validation and GET work without JavaScript. The server remains authoritative for validation. Enhanced submit checks the entire trimmed ASCII positive integer, rejects signed/fractional/exponential/partial/unsafe/out-of-range values, associates an inline error and focuses the field. It retains raw input. Submitting the current page keeps focus, does not navigate and publishes one polite no-op result. Repeated delivery clears the live text before publishing; there is no navigation while typing/blur. Display formatting does not enable localised digit parsing.

pageHref supplies every link/jump destination. linkAttributes(page) supports native integration. Optional onNavigate(page,{href,source}) intercepts eligible primary activations/valid jump requests; modifiers, alternate targets and downloads stay native. The component never commits another currentPage itself. The runnable host demonstrates loading with unchanged current/results, success-only URL/title/page commit and results-heading focus, failure/retry with initiating focus retained, stale-request guards, and Back/Forward without the deliberate-navigation focus policy. Testing found and fixed initial-history restoration when the original URL omitted page (the example's explicit default is 500).
