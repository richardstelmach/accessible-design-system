# Patterns

Patterns define reusable layout, interaction and accessibility guidance for the design system.

Pattern files may be documented in different formats depending on their purpose:

- `.yaml` files are machine-readable pattern specifications.
- `.md` files are human-readable guidance for designers, developers and AI-assisted workflows.

## Existing pattern specifications

- `card-grid.yaml`
- `content-block.yaml`
- `documentation-page.yaml`
- `form-layout.yaml`
- `iconography.yaml`
- `page-layout.yaml`
